# סקריפטים לניהול Windows ו־RDS

הסקריפטים מבוססים על הקבצים של Amr Assi. בתיקייה המקורית היו ארבעה קבצים, ושניים מהם זהים לחלוטין. פורסמו שלוש גרסאות עם פרמטרים ודוגמאות כלליות, ללא שמות לקוחות, משתמשים, שרתים או סיסמאות מהמקור.

| סקריפט | מה הוא עושה |
| --- | --- |
| **Find-RdsProfileDisk.ps1** | מחפש זיהוי של משתמש בפרטי הדיסקים בכמה שרתי RDS ומחזיר מועמדים לבדיקה. |
| **New-ADUsersFromTemplate.ps1** | יוצר משתמשי Active Directory מקובץ CSV, מעתיק מאפיינים נבחרים ממשתמש תבנית ומוסיף לקבוצות שנבחרו במפורש. |
| **Start-RdsShadowSession.ps1** | מציג חיבורי משתמשים בשרת ומאפשר לפתוח צפייה בחיבור מסוים, או שליטה באמצעות הפרמטר Control. |

## מה שופר לפני הפרסום

- הוסרו פרטי הארגונים והסיסמה הקבועה. הקבצים המקוריים במחשב לא שונו.
- איתור דיסק אינו מוצג כהוכחה לפרופיל נעול. כשל בגישה לשרת מוצג בנפרד.
- קטע הניתוק האוטומטי של דיסק הפרופיל הושמט, משום שהפקודה וההודעה על הצלחה לא אומתו.
- יצירת משתמשים תומכת ב־WhatIf. כברירת מחדל החשבונות נוצרים מושבתים, והקבוצות מועתקות רק לאחר בחירה מפורשת.
- הסיסמה נקלטת בצורה מאובטחת בזמן ההפעלה. דוגמת ה־CSV מכילה משתמשי מעבדה בלבד.
- סקריפט Shadow אינו מבקש לעקוף את בקשת ההסכמה ואינו משנה מדיניות בשרת.

## הערך המקצועי

הפרויקטים מציגים ניסיון בתמיכת RDS, תהליכי קליטת משתמשים, עבודה עם PowerShell Remoting ואבחון פרופילים. לכל כלי יש תוצאה מוגדרת והבחנה בין הצלחה, ממצא שדורש בדיקה וכשל.

הבדיקות האוטומטיות משתמשות בנתוני בדיקה ובפקודות מדומות. הן אינן מעידות שהגרסאות המעודכנות הופעלו מול שרתי לקוח.
